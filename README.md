# CSharp-Etapa1-Fundamentos 

**Mi ruta de aprendizaje en C# - Etapa 1 de 6**

Este repositorio contiene los primeros 10 proyectos de mi plan integral de 50 proyectos para dominar C# y el desarrollo de software. 

El objetivo principal de esta primera etapa es construir una base lógica sólida y dominar las herramientas fundamentales del lenguaje mediante la resolución de problemas reales en aplicaciones de consola, antes de introducir la Programación Orientada a Objetos (POO).

## Conceptos Aplicados en esta Etapa
Durante el desarrollo de estos proyectos, puse en práctica los siguientes fundamentos:
- Declaración de Variables y manejo de Tipos de Datos (`int`, `double`, `string`, `bool`).
- Entrada y Salida de datos interactiva (`Console.ReadLine`, `Console.WriteLine`).
- Conversiones y parseo de datos.
- Operadores aritméticos, relacionales y lógicos.
- Estructuras de control de flujo y decisión (`if`, `else if`, `else`, `switch`).
- Estructuras iterativas y bucles (`while`, `do-while`, `for`).
